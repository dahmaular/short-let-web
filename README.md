# ShortLet - Vacation Rental Platform

A modern, visually stunning apartment shortlet/vacation rental platform built with React, TypeScript, and Tailwind CSS. Features a premium design with smooth animations, intuitive UX, and comprehensive booking functionality.

## 🚀 Features

### Core Functionality

- ✅ **Homepage** with hero section, search, categories, and featured properties
- ✅ **Property Listings** with advanced filters, sorting, and grid/list views
- ✅ **Property Details** with image gallery, reviews, and booking card
- ✅ **Booking Flow** with multi-step process and payment (mock)
- ✅ **User Dashboard** for trips, favorites, and profile management
- ✅ **Host Page** with information about becoming a host

### Design Features

- 🎨 Modern, clean design with Tailwind CSS
- ✨ Smooth animations and transitions
- 📱 Fully responsive (mobile, tablet, desktop)
- 🖼️ Image lightbox gallery
- 💫 Micro-interactions and hover effects

## 🛠️ Technical Stack

- **React 18+** with TypeScript
- **Tailwind CSS** for styling
- **Lucide React** for icons
- **Vite** for fast development
- **Context API** for state management

## 🚦 Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Open http://localhost:5173 in your browser

## 📁 Project Structure
